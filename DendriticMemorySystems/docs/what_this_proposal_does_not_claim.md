# What This Proposal Does Not Claim

*A collaborator-facing appendix for reviewers, scientific partners, and readers.*

---

## The Project Does NOT Claim

### About Synthetic-Cell Systems

- That SpudCell is a neural system
- That SpudCell performs neuronal computation
- That SpudCell is an LLM-memory platform or demonstrated cellular memory computer
- That synthetic cells have been demonstrated to function as general-purpose cellular memory computers
- That a computational project requires laboratory access by default
- That a future computational collaboration with a synthetic-biology group is appropriate without mutual scientific interest and clearly bounded scope

### About Biological Neurons and Artificial Neurons

- That artificial neurons are biologically equivalent to biological neurons
- That an external memory record is equivalent to an internal LLM neuron
- That the proposed system reproduces, decodes, or reverse-engineers any LLM's internal representations
- That software retrieval branches are biological dendrites

### About LLM Internals

- That the project will alter the internal weights, attention heads, or hidden states of any foundation model
- That internal LLM parameters constitute a transparent personal memory database
- That internal activations can be directly read as facts, preferences, or isolated memories

### About Performance

- That dendritic-inspired retrieval automatically improves all LLM applications
- That biological inspiration is sufficient evidence of engineering value
- That the proposed system replaces standard RAG, vector search, knowledge graphs, databases, or human verification

---

## What the Project Does Claim

The project claims that:

> Persistent LLM memory can be designed as an **explicit, auditable software system** that makes retrieval decisions using more than semantic similarity alone — incorporating relevance, recency, trust, relationships, conflict status, and user-defined importance.

This claim is **empirically testable** and must be evaluated through controlled comparison with baseline retrieval systems, ablation studies, and human assessment.

The project also claims that:

> Biological and synthetic-cell analogies can serve as **disciplined sources of design questions** for computational memory architecture, provided their limits are explicit and their value is measured empirically rather than assumed by analogy.

## A Note on Scientific Collaboration

If this work ever leads to contact with synthetic-biology researchers (e.g., the SpudCell team at the University of Minnesota), the appropriate framing is:

- Request a **scoped scientific conversation**, not broad access to a lab or research platform
- Ask which properties of a synthetic-cell system are accurately describable in a computational design document
- Ask whether publicly shareable papers, protocols, datasets, or conceptual materials exist
- Ask whether a **narrowly scoped computational or modeling contribution** could be useful
- Do not assume that computational work requires or entitles wet-lab collaboration

This framing respects the independence of both research programs and avoids overstating the project's current scope.
